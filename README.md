# Kids Discovery World - content library

The educational content master. It is a set of static files that are served to
the application over HTTPS, so the application can be updated with new
subjects without a new installation.

Nothing in this folder is needed at runtime on the child's device. Everything
here is published to GitHub Pages.

## Layout

```
content/
  library.json              the release information
  image-sources.json         which pictures to fetch, and what to search for
  attributions.json          licence details for every picture
  images/                    the WebP pictures (generated by the tool)
  packs/<pack-id>/           one folder per subject
    <pack-id>.src.json       the authored pack
tools/
  content_lib.py             the validation rules, shared by the tools
  validate_content.py        check every pack
  build_content.py           build dist/ and the manifest
  fetch_images.py            download and convert pictures from Wikimedia Commons
  make_seed_content.py       regenerate the seed packs
  authoring/index.html       the browser based content editor
.github/workflows/publish.yml
```

## Everyday commands

```bash
python tools/validate_content.py          # check the content
python tools/build_content.py             # build dist/ and manifest.json
python tools/fetch_images.py --all        # fetch the pictures
python -m http.server 8080                # look at dist/ locally
```

`fetch_images.py` needs Pillow: `pip install Pillow`.

## The seed content

25 subject packs with 150 topics and 250 questions, written for a seven year
old: General Knowledge, Animal Kingdom, Birds and Insects, Marine Life, Space
and Astronomy, Geography, Countries Flags and Capitals, UAE Discovery, Science
and Nature, Human Body, Plants and Environment, Mathematics, English Language,
History and Civilisations, Machines and Technology, Vehicles and Transport,
Famous People, Inventions and Discoveries, World Landmarks, Cultures and
Festivals, Health and Hygiene, Life Skills and Safety, Art and Music, Sports
and Games, and Logical Thinking.

Regenerate it with `python tools/make_seed_content.py`.

## Pictures

Every picture comes from Wikimedia Commons and is either public domain or a
Creative Commons licence. The creator, the licence name, the licence link and
the source page are stored in `content/attributions.json` and in the pack that
uses the picture, so the credit is shown in the application even when the
device is offline.

The pictures are stored as WebP: a full size version (1280 px wide) and a
thumbnail (320 px wide). They are content addressed by the build, so the same
picture used by two subjects is stored and downloaded once.
